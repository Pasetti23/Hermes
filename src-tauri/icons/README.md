# Icons

Generated from `app-icon.png` (project root) via:

```bash
npx tauri icon app-icon.png
```

The 5 files `tauri.conf.json`'s `bundle.icon` expects are committed here:
`32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.icns`, `icon.ico`.

If the logo changes, replace `app-icon.png` at the project root (must be a
square PNG/SVG with transparency — pad it to square first if the source
isn't) and re-run the command above.
